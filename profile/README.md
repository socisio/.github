## About SOCIS

**Security Operation Center Integrated Suites (SOCIS)** builds sovereign, self-hosted cybersecurity platforms and delivers hands-on SOC engineering, incident response, and DFIR services. Our products consolidate the tools a modern SOC needs — detection, investigation, response, OSINT, autonomous triage, and malware analysis — into unified, deployable suites that run air-gapped, on-premise, or in your own cloud.

We work across the full defensive lifecycle: **prepare → detect → investigate → respond → recover**, aligned to recognized frameworks (NIST SP 800-61, MITRE ATT&CK, ISO/IEC 27035, SANS IR, OWASP, PTES).

## Our Platforms

<img src="https://raw.githubusercontent.com/socisio/.github/main/assets/socis_enterprise_logo.png" width="100%">

### [SOCIS Enterprise](https://socis.io/product-enterprise.html)
**Unified Detection, Investigation & Response**
Flagship platform consolidating 5–10 separate security tools into a single sovereign command plane — real-time monitoring, ML anomaly detection, deep-dive IOC analysis, automated alerting, and SOAR/SIEM distribution. Supports air-gapped, on-premise, and sovereign cloud deployment.

<br>

<img src="https://raw.githubusercontent.com/socisio/.github/main/assets/socis_trace_logo.png" width="100%">

### [SOCIS Trace](https://socis.io/product-trace.html)
**Self-Hosted OSINT Investigation Workbench**
Unifies identity, infrastructure, artifact, and financial-crime workflows for security researchers, incident responders, journalists, and analysts — username enumeration, domain/IP intelligence, reverse image search, ransomware watch, and crypto tracing in one self-hosted workbench.

<br>

<img src="https://raw.githubusercontent.com/socisio/.github/main/assets/socis_sentinel_ai_logo.png" width="100%">

### [SOCIS Sentinel AI](https://socis.io/product-sentinel-ai.html)
**Autonomous AI Agent Platform for Cyber Defense**
Sovereign LLM-powered agents that automate alert triage, threat hunting, and malware analysis — autonomous tier-1/tier-2 event evaluation with false-positive suppression, built for teams that need SOC coverage without linearly scaling headcount.

<br>

<img src="https://raw.githubusercontent.com/socisio/.github/main/assets/socis_hexcage_logo.png" width="100%">

### [SOCIS HexCage](https://socis.io/product-hexcage.html)
**Malware Sandbox & Payload Extraction**
Isolated detonation environment for executing and instrumenting malicious files — dynamic API hooking, process injection tracing, and registry monitoring for behavioral analysis and forensic artifact collection.
